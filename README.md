# 🧠 CTF Walkthroughs

A collection of hands-on cybersecurity and penetration-testing walkthroughs documenting my progress through **TryHackMe (THM)** and **Hack The Box (HTB)** labs.

The goal of this repository is to document practical attack methodology rather than simply record flags — including reconnaissance, enumeration, initial access, exploitation, credential discovery, privilege escalation, and post-exploitation.

> ⚠️ **Educational Use Only**
>
> All techniques documented here are performed against intentionally vulnerable machines in authorized lab environments such as TryHackMe and Hack The Box.
> Do not use these techniques against systems without explicit authorization.
